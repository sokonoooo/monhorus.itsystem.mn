## 3. Мэдэгдэл — суваг тус бүрээр

### 3.1 Апп доторх мэдэгдэл — **үнэгүй, аль хэдийн ажиллаж байна**

Backend + MongoDB дээр бичигдэнэ. Нэмэлт үйлчилгээ шаардахгүй. Нэмэлт
зардал бол зөвхөн дискний зай — нэг мэдэгдэл ~200 байт.

### 3.2 Android push (FCM) — **үнэгүй**

Firebase Cloud Messaging нь **Spark (үнэгүй) төлөвлөгөөнд хязгааргүй**.
Мессежийн тоогоор төлбөр авдаггүй. Энэ бол Google-ийн олон жилийн бодлого.

Шаардагдах зүйл:
* Firebase төсөл — **үнэгүй**
* Service account түлхүүр — **үнэгүй**
* Google Play Console — Android апп **дэлгүүрээр тараах** тохиолдолд нэг
  удаагийн бүртгэлийн төлбөр. Гэхдээ Монхорус нь APK-г шууд
  `https://monhorus.itsystem.mn/apk/` дээрээс тараадаг тул **Play Console
  огт шаардлагагүй**. Push нь Play Store-оос хамаардаггүй.

> Шалгах: https://firebase.google.com/pricing — FCM мөрийг хар.

### 3.3 iOS push — **жилийн төлбөртэй**

Хэрэв iOS-ийг нэмэхээр шийдвэл:

| Зүйл | Загвар | Тайлбар |
|---|---|---|
| Apple Developer Program | **жилийн төлбөр** | Гарцаагүй. Үүнгүйгээр APNs түлхүүр үүсгэх боломжгүй |
| APNs Auth Key (`.p8`) | **үнэгүй** (гишүүнчлэлд багтана) | Нэг түлхүүр бүх апп, dev+prod |
| APNs мессеж | **үнэгүй** | Тоогоор төлбөргүй |

Түүнчлэн **нэмэлт ажил**: харилцагчийн аппын bundle id
solih ажил 2026-08-18-нд хийгдсэн (`mn.itsystem.monhorus`); signing team тохируулах, Xcode
capability нэмэх. Энэ нь мөнгө биш, цаг.

> Шалгах: https://developer.apple.com/programs/

### 3.4 Имэйл (нууц үг сэргээх) — **сонгосон замаар**

Backend дээр **ганцхан** имэйл байдаг: нууц үг сэргээх. Хэмжээ нь маш бага —
хэдэн арваас хэдэн зуун захидал/сар.

| Сонголт | Загвар | Тайлбар |
|---|---|---|
| **Gmail App Password** ← сонгосон | **үнэгүй** | Өдөрт ~500 хүлээн авагч. Одоогийн хэрэглээнд асар хангалттай |
| Google Workspace | сарын, хэрэглэгчээр | Аль хэдийн байгаа бол нэмэлт зардалгүй, хязгаар ~2000/өдөр |
| `itsystem.mn`-ий өөрийн мэйл сервер | **үнэгүй** | Аль хэдийн байгаа бол. SPF/DKIM аль хэдийн тохирсон байх магадлалтай |
| Amazon SES / Resend / Postmark | хэрэглээгээр, үнэгүй давхаргатай | Энэ хэмжээнд ихэвчлэн үнэгүй давхаргад багтана |

**Gmail-ийн далд зардал — мөнгө биш, эрсдэл:**

* `MAIL_FROM=no-reply@monhorus.itsystem.mn` гэж тавьбал Gmail түүнийг
  **дарж, өөрийн хаягаар** солино (эсвэл SPF унана). Тиймээс эсвэл
  `MAIL_FROM`-ыг Gmail хаяг болгох, эсвэл "Send mail as" баталгаажуулалт
  хийх шаардлагатай. Дэлгэрэнгүйг `.env.example` дээр бичсэн.
* App Password нь 2FA шаарддаг.
* Gmail-ээр илгээсэн захидал spam руу орох магадлал transactional
  provider-оос **өндөр**.

Хэрэв нууц үг сэргээх нь хэрэглэгчдэд бодитоор нээгдэх бол, дунд хугацаанд
transactional provider руу шилжихийг зөвлөж байна — үнэгүй давхарга нь
энэ хэмжээг бүрэн барина.

## 5. Дискний зай — бодит хязгаарлалт

Сервер **83% дүүрсэн, 3.9 GB сул** (`PRODUCTION_STATUS.md:21`). Энэ нь
мөнгөний бус, бодит хязгаар.

Мэдэгдлийн ажил үүнд хэрхэн нөлөөлөх вэ:

| Зүйл | Нөлөө |
|---|---|
| `firebase-admin` **ашиглаагүй** | ~тэмдэгтийн олон арван MB хэмнэсэн — FCM-ийг REST API-аар дуудсан |
| `notifications` цуглуулга | 6 шинэ эвент идэвхжсэн тул өсөлт нэмэгдэнэ |
| `devicetokens` цуглуулга | маш бага — хэрэглэгч тус бүрд 1-2 мөр |
| Flutter аппын хэмжээ | firebase_messaging нэмснээр APK ~2-4 MB томроно |

**Зөвлөмж:** мэдэгдлийн хуучин мөрийг цэвэрлэх бодлого (жишээ нь 6 сараас
хуучин, уншсан мэдэгдлийг устгах) авч үзэх. Одоо ийм бодлого **байхгүй** —
цуглуулга хязгааргүй өснө. Энэ нь одоо асуудал биш ч, диск 83% байхад
анхаарах зүйл.
